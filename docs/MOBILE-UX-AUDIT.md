# Аудит мобильного UX — Phase 7

## Обнаружено

1. Хлебные крошки переносились на несколько строк (`flex-wrap`). На вакансии: «Главная / Работа / Вакансии / Торговля / Менеджер по продажам».
2. Заголовок объявления дублировался в крошках и в `<h1>`.
3. `/map` была заглушкой без тайлов.
4. Нижняя навигация не учитывала `safe-area-inset-bottom`.
5. Контент мог уходить под системную панель iPhone (`viewport-fit` не был задан).
6. Фильтры каталога — полноэкранный drawer, но без горизонтальных чипов и без счётчика активных фильтров.
7. `/messages` — каркас без списка диалогов и экрана переписки.
8. Внутренние страницы повторяют полную шапку главной (логотип + поиск).

## Исправлено в этой итерации

- Компактные крошки: на `<sm` одна строка «← Родитель / Текущий», на desktop — полная цепочка. Высота ~36 px.
- Заголовок объявления убран из крошек (`samples/[slug]`).
- Реальная карта Leaflet (см. `MAP-IMPLEMENTATION.md`).
- `safe-area-inset-bottom` на нижней навигации и отступ `body`.
- `viewport-fit: cover` в `viewport` корневого layout.
- Карта на мобайле не перекрывается нижней панелью.

## Проверено

| Страница | 390 | 1600 | Замечание |
|---|---|---|---|
| Главная | да | да | Дизайн сохранён |
| Каталог / транспорт | да | да | Drawer фильтров на мобайле |
| Объявление (вакансия) | да | — | Крошки в одну строку |
| Карта | да | да | Тайлы OSM, 70 DEMO-пинов |
| Поиск / избранное / кабинет | ранее Phase 6 | — | Без регрессий сборки |

## Не закрыто в этой итерации

- Отдельная шапка внутренних экранов («Назад» + короткий заголовок вместо глобального поиска).
- Горизонтальные чипы фильтров + полноэкранная панель «Все фильтры» с кнопкой «Показать N».
- Переработка иерархии карточки объявления под референс (заголовок → цена → фото → характеристики).
- Полноценный UI сообщений (список / диалог) с DEMO-перепиской.
- Скрытие нижней навигации на чате, полноэкранной галерее и клавиатуре.
- Playwright E2E (14 сценариев из брифа).
- Проверка всех ширин 320–430 и планшетов 768/1024 в автоматическом прогоне.
