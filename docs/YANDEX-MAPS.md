# Яндекс Карты — интеграция Phase 8

## Лицензия и ключ

- Используется только официальный JavaScript API 3.0: `https://api-maps.yandex.ru/v3/`.
- Ключ обязателен и должен иметь ограничение HTTP Referer (`localhost:3100`, затем домен сайта).
- Получение: [Кабинет разработчика](https://developer.tech.yandex.ru/), пакет «JavaScript API и HTTP Геокодер».
- Платный HTTP Геокодер и другие платные сервисы не вызываются.
- Кластеризация: официальный `@yandex/ymaps3-clusterer` через `ymaps3.import`.
- Координаты API: `[долгота, широта]`. В URL остаются `lat`, `lng`, `z`.

## Переменная окружения

```
NEXT_PUBLIC_YANDEX_MAPS_API_KEY=...
```

Без ключа на `/map` показывается состояние «Требуется настройка Яндекс Карт». Если ключ задан, но API отвечает 403 Invalid api key, показывается «Яндекс отклонил API-ключ». Список объявлений при этом работает. OSM, Leaflet и iframe не используются как подмена.

## Тесты

Прогон без ключа не считается подтверждением работы картографического сервиса. После появления ключа с Referer нужно отдельно проверить загрузку SDK, маркеры и кластеры.
