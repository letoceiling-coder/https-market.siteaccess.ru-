# Отчёт по адаптивности

Дата: 2026-11-01. Сборка: Next.js 16.4.3 production (`next start`, порт 3100). `UI_DEMO_MODE=true` из `.env.local`.

## Условия

- Desktop: headless Chrome 1600×900 через `scripts/shot.py`.
- Mobile: iframe-обёртка 390×844 (headless Chrome не умеет окно уже ~500 px).
- Интерактив: Cursor browser на реальной ширине вкладки (~390 px) + CDP `Emulation.setDeviceMetricsOverride` 1440×900.

## Результаты

| Экран | Ширина | Результат |
|---|---|---|
| `/map` desktop | 1600 | Сайдбар + карта, тайлы OSM, пилюли с ценой, атрибуция Leaflet \| OSM |
| `/map` mobile | 390 | Чипы, карта, bottom sheet «Найдено 70 (DEMO)», кнопка «Список», нижняя навигация |

| `/map` CDP mobile | ~370 | Один контейнер 370×578, 8 тайлов загружены, 70 пинов |
| `/samples/job-sales` 390 | 390 | Крошки одной строкой «← Вакансии / Торговля», заголовок не дублируется |
| `/catalog/transport` 390 | 390 | Drawer «Фильтры и сортировка», 2 колонки карточек |

## Известные ограничения съёмки

На мобайле карта `position: fixed` — iframe-скриншот иногда показывает лист поверх тайлов (sheet в состоянии half). В живом браузере тайлы видны: CDP подтвердил `tilesLoaded === tileCount`.

Ширины 320, 375, 414, 430, 768, 1024 в этом прогоне не снимались покадрово. Критичные экраны (карта, крошки, каталог) проверены на 390 и 1600.

## Регрессии

Горизонтального скролла на проверенных экранах нет. Нижняя навигация не перекрывает контент (у `body` есть `pb-[calc(3.5rem+env(safe-area-inset-bottom))]`).
