# HELP HOMES — визуальный разрыв с уровнем Avito

Дата: 1 ноября 2026.  
Измерения HELP HOMES сняты в живом `localhost:3100` через DevTools (`getBoundingClientRect` + `getComputedStyle`).  
Референс Avito: живая главная avito.ru (десктопная композиция) и предыдущий пиксельный замер V5 в `docs/UI-REFERENCE-AUDIT.md`.  
Логотипы, иллюстрации и код Avito не копировались. Сравниваются сценарии, плотность и геометрия.

Скриншоты «до»: `docs/screenshots/phase8-before-home-320.png`, `docs/screenshots/phase8-before-map-320.png`.

## Лицензия Яндекс Карт (проверка до интеграции)

| Вопрос | Факт |
|---|---|
| Продукт | JavaScript API 3.0, официальная загрузка `https://api-maps.yandex.ru/v3/` |
| Ключ | Обязателен. Ключ JS API 3.0 работает только с заполненным ограничением HTTP Referer |
| Где взять | [Кабинет разработчика Яндекса](https://developer.tech.yandex.ru/), пакет «JavaScript API и HTTP Геокодер» |
| Активация | До 15 минут после выдачи |
| Кластеризация | Официальный пакет `@yandex/ymaps3-clusterer` через `ymaps3.import` |
| Координаты API | `[долгота, широта]` (GeoJSON). В URL оставляем привычные `lat`, `lng`, `z` и конвертируем на границе |
| Геокодер / платные вызовы | Не подключаем без отдельного разрешения. Поиск по городу и категории идёт по своим данным |
| Текущий ключ | В `.env.local` ключа нет. Карта не может легально отрисовать тайлы Яндекса |
| Что нельзя | Подменять карту OSM, Leaflet, iframe или скриншотом и выдавать это за Яндекс Карты |

## Расхождения

### G1. Мобильная шапка: регион не помещается

1. **Страница.** Главная, каталог, поиск, карта — все экраны с глобальной шапкой.  
2. **Текущее.** Один ряд: логотип 17 px + «Все регионы» + избранное + сообщения. На 320 px подпись региона обрезается посередине слова.  
3. **Целевое.** Компактный логотип, короткое имя региона, иконки 44×44. Если ряд не сходится — два уровня, без обрезки слов.  
4. **Серьёзность.** Высокая.  
5. **Исправление.** Двухуровневая шапка: ряд 1 — логотип / регион / действия; ряд 2 — поиск и вход в каталог. Для «все регионы» показывать «Россия», а не длинную фразу.  
6. **Критерий.** На 320×579 «Россия» или имя города читается целиком; высота шапки ≤ 104 px.

### G2. Нет быстрого входа в каталог на мобильной главной

1. **Страница.** Главная.  
2. **Текущее.** Кнопка «Все категории» есть только в десктопной шапке.  
3. **Целевое.** Очевидный вход в каталог рядом с поиском.  
4. **Серьёзность.** Высокая.  
5. **Исправление.** Кнопка «Категории» во втором уровне шапки + плитка «Все категории» в мозаике.  
6. **Критерий.** На 320 px кнопка каталога видна без прокрутки категорий.

### G3. Категории на 320 px обрезаются

1. **Страница.** Главная.  
2. **Текущее.** Горизонтальная сетка 172×76, две строки. Вторая колонка обрезана. «Жильё для путешествий» и «Для дома и дачи» переносятся неравномерно. Нет края карусели и нет «Все категории». Нет аренды, спорта, бизнеса, строительства.  
3. **Целевое.** Компактные карточки или карусель с понятной границей; подписи целиком по словам; фото не перекрывают текст; полный набор направлений.  
4. **Серьёзность.** Блокер приёмки.  
5. **Исправление.** Мобильные плитки ~148×64, подпись 12/15, фото ≤ 28 % ширины, `scroll-padding`, градиентный край, последняя плитка «Все категории». Десктоп — широкие плитки.  
6. **Критерий.** На 320 px ни одна видимая подпись не режется посередине слова; виден край следующей плитки или кнопка «все».

### G4. Лента: заголовок в одну строку и ломаная сетка

1. **Страница.** Главная, поиск, избранное.  
2. **Текущее.** `line-clamp-1` на обычных карточках. Вакансии/услуги на мобайле занимают две колонки (`listOnMobile`). На 320 px в первом экране не видно цены — её вытесняет шапка + категории + заголовок.  
3. **Целевое.** Две колонки, квадратное фото, заголовок до двух строк, цена 16–18 px жирным, факты / место / дата / избранное.  
4. **Серьёзность.** Высокая.  
5. **Исправление.** Единая сетка 2 колонки; `line-clamp-2`; `overflow-wrap: anywhere` только на границах слов через `hyphens-none` + укороченные заголовки; вакансии остаются в сетке.  
6. **Критерий.** На 320 и 390 карточки одной высоты ряда; цена видна; текст не вылезает.

### G5. Регион не влияет на выборку

1. **Страница.** Главная, каталог, поиск, карта.  
2. **Текущее.** Регион пишется только в `localStorage`. Лента и карта его игнорируют. В справочнике нет Коми / Сыктывкара.  
3. **Целевое.** Смена региона сужает объявления и двигает карту. Пустой регион — честное пустое состояние, а не чужие города.  
4. **Серьёзность.** Блокер приёмки.  
5. **Исправление.** Фильтр по `regionId`, центры регионов включая Сыктывкар (61.6688, 50.8364), URL `region`, карта слушает тот же стор.  
6. **Критерий.** «Сыктывкар» → в ленте и на карте нет московских DEMO; карта центрируется на Коми.

### G6. Карта — Leaflet/OSM вместо Яндекс Карт 3.0

1. **Страница.** `/map`.  
2. **Текущее.** Leaflet 1.9 + `tile.openstreetmap.org`. Кластеров нет. 70 точек сразу.  
3. **Целевое.** Официальный JS API 3.0 + `@yandex/ymaps3-clusterer`. Без ключа — экран «Требуется настройка Яндекс Карт», не чужие тайлы.  
4. **Серьёзность.** Блокер.  
5. **Исправление.** Провайдер с ленивой загрузкой скрипта только на `/map`; ключ `NEXT_PUBLIC_YANDEX_MAPS_API_KEY`; честный setup-state.  
6. **Критерий.** В DOM нет `.leaflet-container`. При отсутствии ключа виден setup-state. При ключе — слой Яндекса.

### G7. Мобильная карта перекрыта панелью и глобальной шапкой

1. **Страница.** `/map` 320/390.  
2. **Текущее.** Глобальная шапка 101 px + поиск + чипы. Sheet `46vh` (266 px из 579). Карта почти не управляется. «Список» перекрывает вторую карточку. Footer 801 px в потоке.  
3. **Целевое.** Компактная шапка с «Назад», поиск, чипы, карта на остаток, плавающие контролы, sheet 80–110 / ~50% / почти весь экран, переключатель «Карта / Список» вне карточек.  
4. **Серьёзность.** Блокер.  
5. **Исправление.** Отдельный мобильный chrome карты; скрыть footer; sheet на три якоря; кнопка списка в шапке или над ручкой.  
6. **Критерий.** В collapsed видно ≥ 55 % высоты экрана карты; «Список» не пересекает карточки.

### G8. Нет поиска в видимой области и нет синхронизации списка с маркером

1. **Страница.** Карта.  
2. **Текущее.** Фильтр только по `kind`. Выбор в списке не гарантирует скролл обратно. Кластеров нет.  
3. **Целевое.** Debounce bounds, подсветка, скролл к карточке, превью, кластер.  
4. **Серьёзность.** Высокая.  
5. **Исправление.** `MapSearchArea`, общий стор выбранного id, clusterer.  
6. **Критерий.** Сдвиг карты обновляет счётчик не чаще 1 раза / 400 ms; клик по маркеру скроллит список.

### G9. Фильтры каталога не похожи на приложение

1. **Страница.** Каталог / подкатегория.  
2. **Текущее.** Одна кнопка «Фильтры и сортировка», форма без чипов, без «Показать N», без черновика.  
3. **Целевое.** Горизонтальные чипы + полноэкранная панель: Назад / Фильтры / Сбросить и закреплённая «Показать результаты».  
4. **Серьёзность.** Высокая.  
5. **Исправление.** `FilterChipBar` + `FilterSheet` с локальным draft.  
6. **Критерий.** Чип «Цена» виден на 320; закрытие панели не теряет черновик; URL содержит применённые поля.

### G10. Карточка объявления дублирует глобальный поиск

1. **Страница.** `/samples/[slug]` 390.  
2. **Текущее.** Полная шапка + поиск + крошки + h1 + цена + галерея. «Написать» на `bottom-14`, нижняя навигация остаётся. Нет «Поделиться».  
3. **Целевое.** Назад / избранное / поделиться; цена сразу; галерея; характеристики; продавец; похожие; закреплённые действия без перекрытия.  
4. **Серьёзность.** Средняя / высокая.  
5. **Исправление.** Компактный chrome внутренних экранов; `pb` под бар действий + bottom nav.  
6. **Критерий.** На 390 поиск не занимает первый экран карточки; CTA не перекрывает описание.

### G11. Сообщения, кабинет, внутренние страницы — другой уровень качества

1. **Страница.** `/messages`, `/account`, партнёрский кабинет, реклама, инфостраницы.  
2. **Текущее.** Каркасы и пустые состояния без списков, без мобильной плотности ленты.  
3. **Целевое.** Та же типографика, отступы 16, карточки 44 px tap, единый chrome.  
4. **Серьёзность.** Средняя.  
5. **Исправление.** Общий `AppScreen` и демо-диалоги с пометкой DEMO.  
6. **Критерий.** 320 px: заголовок + контент читаются, нижняя навигация не перекрывает последнее поле.

### G12. Навигация и сохранение контекста

1. **Страница.** Каталог → карточка → назад.  
2. **Текущее.** `prefetch={false}` на карточках. Регион не в URL. Прокрутка списка не восстанавливается.  
3. **Целевое.** Штатный `Link` с prefetch по умолчанию, фильтры в URL, scroll restoration.  
4. **Серьёзность.** Высокая.  
5. **Исправление.** Убрать принудительный `prefetch={false}`; `sessionStorage` позиции; `region` в query.  
6. **Критерий.** Переход по карточке без document reload; возврат восстанавливает фильтры и ±24 px прокрутки.

## Известные ограничения аудита

- Эмуляция 390 на avito.ru в Cursor browser осталась на десктопной вёрстке (UA Windows, ширина контейнера ~1007). Мобильный референс Avito опирается на бриф и V5-замер, не на пиксельный кроп чужого приложения.
- Тесты Яндекс Карт с живым SDK невозможны без ключа с Referer. Отсутствие ключа не считается поломкой интеграции, если показан setup-state.
